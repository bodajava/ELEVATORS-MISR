# reference/

Private source material used to write site content. **Not published, not committed.**

`private/` is git-ignored and must stay that way. It holds
`company-work-history-2025.pdf` — the company's own work-history record
(سابقه اعمال الشركه لعام 2025), copied byte-identically from the user's Downloads
folder on 2026-08-06. The original was left in place.

Rules for anything in `private/`:

- It is **source material for verification only**. Facts may be read from it; the file
  itself is never served, linked, or copied into `public/`.
- **Never publish** client names, personal addresses, villa or unit numbers, phone
  numbers, or any other identifying detail found inside it.
- Any figure quoted on the site must be **directly supported** by this document and must
  not imply that every entry is a panorama elevator project.
